Getting Started with This Tool

This extension translates web pages into your language while keeping technical content intact. The main goal is to help developers read documentation on GitHub and AI websites without confusion.

A quick note: the text in this paragraph should be translated into Chinese.

Installation

First, clone the repository with git clone https://github.com/user/repo.git and then open the folder in your editor.

$ git clone https://github.com/user/repo.git
$ cd repo
$ npm install
$ npm run build
# then open chrome://extensions and load the unpacked folder

If the installation fails, check that your Node.js version is newer than 18 and that the API key is valid.

Core Concepts

  • A Pull Request lets you propose changes to a repository before merging.
  • The JSON configuration file must be valid, otherwise the build stops.
  • TypeScript types help catch errors during development.
  • Large Language Models can summarize long documents quickly.

Read the official documentation at the project homepage for more details.
